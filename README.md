# ApplyPilot

A C++ job application tracker that helps users organize job applications, monitor interview progress, and review their job search activity.

## Features

- Add and view job applications
- Track application statuses
- Search for companies
- View job search statistics
- Save application data to a file

## Technologies

- C++
- CMake
- Git and GitHub

## Getting Started

### Requirements

- A C++ compiler
- CMake
- CLion or another C++ development environment

### Run the Project

1. Clone this repository.
2. Open the project in CLion.
3. Allow CMake to load the project.
4. Build and run the application.

## Project Goals

This project is designed to practice C++ programming, data management, file handling, and software development fundamentals.
